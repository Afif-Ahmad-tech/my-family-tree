The family tree that never leaves your browser.

Family Chart is a free family tree app and the D3 library behind it. Add relatives, explore the tree, and export a plain JSON backup. There is no account to create and no server to trust.

Why local

One rule: the data stays yours.

Most family tree services keep your relatives on their servers and ask you to trust them. This one keeps everything in the browser you are already using.

Private by default

The tree lives in this browser's local storage. There is no backend to sign into, no sync to configure, and nothing sent anywhere.

Look first, edit second

The tree fills the screen. Click a person to read their details and switch to Edit only when something needs correcting.

Yours to keep

Export writes the whole tree to a JSON file and Import reads it back on another machine. A plain file is the backup.

Features

A tree you can read, edit, and embed.

The app runs on the same published library that you can install into your own project.

Pan, zoom, focus

Drag the canvas, scroll to zoom, and click any card to make that person the centre of the tree.

HTML or SVG cards

Render cards as HTML for rich layouts or as SVG for crisp scaling, then choose which fields each card shows.

Add anyone

From a selected person, add a partner, child, or parent. Every edit has a visible way out.

TypeScript first

Typed entry points for Chart, CardHtml, and EditTree, with a generated TypeDoc reference.

Framework agnostic

Use it with plain JavaScript, React, Vue, Angular, or Svelte. No wrapper package required.

Style it your way

Cards, colours, and layout are configured through the public API and one stylesheet.

Quick start

Two ways to start.

Open the app if you just want your own tree. Install the library if you are building a tree into something else.

Use the app

  1. 1

    Open the tree

    Start from the example family, then replace it with your own.

  2. 2

    Add your people

    Pick a person, switch to Edit, and add a partner, child, or parent.

  3. 3

    Keep a backup

    Export writes the whole tree to a JSON file you can import anywhere.

Open the app

Embed the library

$ npm install family-chart d3 

import * as f3 from 'family-chart'
import 'family-chart/dist/styles/family-chart.css'

const chart = f3.createChart('#FamilyChart', data)
  .setCardHtml()
  .setCardDisplay([
    ['first name', 'last name'],
    ['birthday'],
  ])

chart.updateTree({ initial: true })
